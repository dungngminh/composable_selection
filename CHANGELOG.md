# Composable Selection's Changelog

## [1.0.3] - 2026-03-01

### Changed

- Remove Composable-only selection restriction, now selects any function call.

### Fixed

- Fix keyboard shortcut not working on IntelliJ 2025.* by adding `ActionUpdateThread.BGT`.
- Change keyboard shortcut from `Ctrl+Shift+W` to `Ctrl+Alt+W` to avoid conflict with built-in Shrink Selection.
